How to Use the Robots.txt Generator

  1. Add one rule group per crawler: set the User-agent (use * for all bots), plus the paths to allow or disallow.
  2. Optionally add your sitemap URL and a crawl delay in seconds.
  3. Click "Generate robots.txt" to preview the finished file.
  4. Download it and upload it to the root of your domain so search engines can read it.

Why Use a Robots.txt File?

A robots.txt file is a simple set of instructions that tells search-engine crawlers which parts of your site they may visit and which they should skip. Blocking admin pages, staging folders or thin content saves your crawl budget for the pages that actually matter.

  • Dynamic rule rows — add as many user-agent groups as you need, remove them anytime.
  • Allow & disallow paths — fine-grained control over what crawlers can reach.
  • Sitemap & crawl-delay — point bots at your sitemap and slow aggressive crawlers.
  • Correct formatting — groups are spaced and ordered the way crawlers expect.
  • Private & free — generated in your browser, no sign-up, no limits.

Frequently Asked Questions

Where does the robots.txt file go?

In the root of your domain — for example, https://example.com/robots.txt. Crawlers always look there first, so the file will not work in a subfolder.

What does "User-agent: *" mean?

The asterisk matches every crawler. You can also add separate rows for specific bots, e.g. Googlebot, if you want different rules for them.

Does Disallow hide a page from Google?

Not exactly. Disallow stops crawling but does not stop indexing — a blocked page can still appear in results if other sites link to it. Use noindex or a password for pages that must stay private.

Is a crawl delay supported by Google?

No, Googlebot ignores the crawl-delay directive. Other crawlers honour it, so it is still useful for slowing down aggressive bots.
