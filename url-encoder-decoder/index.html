How to Use the URL Encoder / Decoder

  1. Paste the full URL or query-string value you want to convert into the input box.
  2. Choose "Encode URL" or "Decode URL" for complete links, or the "Component" buttons for individual query values.
  3. Copy the result from the output box with one click and use it in your code, links or redirects.

Why Two Encoding Modes?

URLs can only safely contain a limited set of characters — spaces, quotes and many symbols must be percent-encoded (turned into codes like %20) before a browser or server will accept them. But not every character should be encoded in every situation, which is why this tool offers two modes.

  • Full-URL encoding leaves the characters that give a URL its structure intact — such as : / ? # and & — and only encodes the unsafe ones. Use it on complete links.
  • Component encoding is stricter: it encodes everything that could break a query string, including ? & = and /. Use it when you drop a value into a parameter, e.g. the search term in ?q=hello&world.
  • Decoding included — turn percent-encoded strings back into readable text with the matching decode buttons.
  • Error protection — malformed input (like a lone % or bad %XX code) is flagged instead of crashing.
  • Character counts — see input and output lengths at a glance, handy when you are watching URL length limits.
  • 100% private — all conversion happens on your device; no links are ever uploaded.

Frequently Asked Questions

What is the difference between Encode URL and Encode Component?

"Encode URL" keeps structural characters like : / ? # & untouched so the link still works — use it on whole URLs. "Encode Component" encodes those too, which is what you want for a single value going inside a query parameter.

When should I decode a URL?

When you copy a link from a browser or log and it shows codes like %20, %3A or %2F instead of spaces, colons and slashes. Decoding restores the readable form.

Why do I see an "Invalid encoded input" error?

The text contains a malformed percent sequence — for example a % not followed by two hexadecimal digits. Check the input and try again; valid encoded strings always use the %XX format.

Are my URLs sent to a server?

No. Encoding and decoding are done with JavaScript in your own browser, so nothing you paste ever leaves your device.
