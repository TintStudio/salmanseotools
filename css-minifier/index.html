How to Use the CSS Minifier

  1. Paste your full stylesheet into the input box.
  2. Click Minify CSS — comments are stripped and whitespace is collapsed in one step.
  3. Check the byte stats to see exactly how much smaller the file became.
  4. Copy the result or download it as style.min.css and link it from your pages.

Why Minify CSS?

Every extra byte in a stylesheet is a byte every visitor must download. Minification removes comments, line breaks and spaces that humans need but browsers don't, shrinking the file and speeding up page loads — a small but real win for user experience and Core Web Vitals.

  • Comment removal — /* ... */ comments are stripped from the output.
  • Whitespace collapsing — redundant spaces, tabs and newlines are removed.
  • Safe punctuation cleanup — spaces around braces, colons, semicolons and commas are trimmed, and the last semicolon in each rule is dropped.
  • Honest stats — see original vs minified size and the exact percentage saved.
  • Private and free — your code never leaves the browser; no account, no limits.

Frequently Asked Questions

Will minification change how my CSS works?

No. This tool only removes comments and whitespace that browsers ignore, so the rendered result is identical. Still, keep your original file and test before deploying.

How much smaller will my CSS get?

It depends on formatting, but hand-written CSS typically shrinks by 20–40%. The stats above show your exact saving.

Does it handle CSS inside HTML style tags?

Paste only the CSS itself, not the surrounding <style> tags, for the cleanest result.

Is my stylesheet uploaded anywhere?

No. Minification runs entirely in your browser with JavaScript — your code stays on your device.
