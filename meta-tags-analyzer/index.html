How to Use the Meta Tags Analyzer

  1. Open the page you want to check, view its source (Ctrl+U) and copy the HTML — the <head> section is enough.
  2. Paste it into the box above and click Analyze Meta Tags.
  3. Review the tag table and fix any warnings, such as a missing description or an over-long title.
  4. Re-paste and re-analyze after making changes to confirm everything is clean.

Why Analyze Meta Tags?

Meta tags are the first thing search engines and social networks read about your page. A missing description, a truncated title or a broken canonical can quietly cost you clicks and rankings. This analyzer gives you the same quick audit an SEO specialist runs before publishing — in seconds and for free.

  • Full tag inventory — title, description, keywords, robots, viewport, canonical, Open Graph and Twitter tags in one table.
  • Smart SEO warnings — flags missing tags and length problems against current best practice.
  • Character counts — see exactly how long your title and description are before Google truncates them.
  • 100% private — parsing happens on your device; nothing is sent to a server.
  • Free forever — no account, no limits, no watermarks.

Frequently Asked Questions

What HTML should I paste?

The <head> section is enough, but pasting the full page HTML works too — the analyzer only reads the head tags.

Is my HTML uploaded anywhere?

No. The HTML is parsed with your browser's built-in DOMParser, so it never leaves your device.

What is the ideal title and description length?

Keep titles between 10 and 60 characters and meta descriptions between 50 and 160 characters so they display fully in search results.

Can it check a live URL directly?

Not directly — browsers block fetching other sites' pages. Copy the page source (Ctrl+U) and paste it here instead.
