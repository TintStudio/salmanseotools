How to Use the HTML Encoder / Decoder

  1. Paste your text, code snippet or HTML into the input box.
  2. Click Encode → Entities to convert special characters like <, >, &, quotes and apostrophes into their entity equivalents.
  3. Click Decode → Text to turn entities such as &lt; back into readable characters.
  4. Copy the result with one click and use it in your page, email or CMS.

Why Encode HTML Characters?

Browsers treat characters like < and > as markup. If you want to display code samples, user input or literal angle brackets on a page, those characters must be escaped as entities — otherwise the browser tries to parse them as tags and your content breaks or disappears.

  • Two-way conversion — encode text to entities and decode entities back, in one place.
  • Correct escaping order — ampersands are encoded first, so existing entities are never double-escaped.
  • Full entity support on decode — named, decimal and hexadecimal entities are all decoded.
  • Instant and private — conversion happens on your device with no server round-trip.
  • Free, no limits — encode as much text as you like, no account needed.

Frequently Asked Questions

What is an HTML entity?

An HTML entity is a text code that represents a special character, e.g. &lt; renders as <. Entities let you display characters that would otherwise be interpreted as HTML markup.

Which characters get encoded?

The encoder converts &, <, >, double quotes and apostrophes — the five characters that must be escaped inside HTML.

Will encoding break my existing entities?

No. Because & is encoded before anything else, an existing entity like &lt; becomes &amp;lt; rather than being mangled — and decoding reverses it cleanly.

Is my pasted code sent to a server?

No. Encoding and decoding run entirely in your browser, so your code never leaves your device.
