How to Use the On-Page SEO Checker

  1. Open the page you want to audit and view its source (Ctrl+U in most browsers), then copy the HTML.
  2. Paste the code into the box above and press "Run SEO Audit".
  3. Review your score out of 100 and the check-by-check table.
  4. Work through the fix tips, update the page, and re-run the audit to watch the score climb.

What the Audit Checks

Search engines read the same HTML your browser does, so the fundamentals of on-page SEO live in the page source. This checker inspects the elements that matter most and scores them, so you can spot problems in seconds instead of reading code line by line.

  • Title tag — present, and between 30–60 characters so it displays fully in search results.
  • Meta description — present, and between 120–160 characters for a clean search snippet.
  • Headings — exactly one H1, plus H2 subheadings that structure the content.
  • Images — every image carries descriptive alt text for accessibility and image search.
  • Technical basics — viewport tag, page language, canonical URL and Open Graph tags.
  • Content depth — a word count check that flags thin pages under 300 words.

Frequently Asked Questions

Is this SEO audit really free?

Yes. Every tool on Salman SEO Tools is free with no sign-up and no usage limits.

Why do I paste HTML instead of a URL?

Browsers block web pages from fetching other websites directly (a security rule called CORS). Pasting the page source gives the same result without any server involved — and keeps the tool 100% private.

Is a score of 100 a ranking guarantee?

No. On-page basics are only one part of SEO — content quality, backlinks and user experience matter too. Treat the score as a health check for the fundamentals, not a promise of rankings.

Does my pasted HTML get uploaded?

No. The audit runs entirely in your browser with JavaScript, so your code never leaves your device.
