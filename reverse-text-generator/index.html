Frequently Asked Questions

What is the difference between the reverse modes?

"Whole text" flips every character so "hello world" becomes "dlrow olleh". "Each word" reverses letters inside words but keeps their order: "olleh dlrow". "Word order" flips the sequence of words: "world hello". "Line order" reverses the order of lines, useful for lists.

Is the reversed text readable?

Character-reversed text reads backwards, which is the point — it is great for puzzles, jokes and stylised posts. Word-order mode stays readable word by word.

Does it work with emojis and special characters?

Yes. The tool reverses by Unicode code point, so emojis and accented characters are handled correctly.
